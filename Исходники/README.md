# Своё место — Екатерина Волкова

## v4 — автономная версия

Готовый сайт работает как набор локальных файлов и на обычном статическом хостинге. Все пути относительные, ссылки между страницами явно указывают `index.html`. Onest с лицензией OFL включён в `dist/assets/fonts`; обращений к Google Fonts нет. Стили, JavaScript и изображения локальные. Для просмотра готового сайта Node.js не нужен.

После правок выполнить `node pages.mjs`, `node check-site.mjs`, `node export.mjs`. Последняя команда копирует готовый сайт в соседнюю папку `Сайт`. Открыть её `index.html` двойным кликом или загрузить её содержимое на хостинг. `preview.mjs` — необязательный инструмент разработчика.

Личный сайт эксперта по недвижимости в Саратове и Москве. Рабочее название: «Своё место».

## Обновление

- Главная страница и общая разметка: `build.mjs`.
- Внутренние страницы: `pages.mjs`.
- Актуальные стили: `dist/design-v3.css`; меню: `dist/site.js`. Предыдущие стили не подключены.
