# Своё место — Екатерина Волкова

Актуальная версия: v8, карта этапов с векторными линиями ветра.

- `Сайт/` — готовый автономный статический сайт; это папка публикации.
- `Исходники/` — обычные файлы для редактирования, без вложенного Git-репозитория.
- `Сайт.zip` — готовый архив. Для просмотра распаковать полностью и открыть index.html.

## Cloudflare Pages
Framework preset: None. Build command: оставить пустым. Build output directory: `Сайт`. Root directory: корень репозитория.

## Обновление
Из папки Исходники: `node pages.mjs`, `node check-site.mjs`, `node export.mjs`.
После изменения загрузить обновлённую папку Сайт и исходники.
Не копировать вложенную папку .git в этот репозиторий.

## Исправление ошибки submodules
Первый коммит хранил Исходники как gitlink (режим 160000) без .gitmodules. Git не мог определить адрес подмодуля; Cloudflare останавливался до сборки. Теперь Исходники содержит обычные файлы, подмодулей нет.
